# unrot

Terminal-based brain training for analytics engineers. Quiz yourself on dbt Core topics to stay sharp and prep for the dbt Analytics Engineering Certification.

## Quick Start

```bash
# Install dependencies
uv sync

# Launch the TUI
uv run unrot start

# List available topics
uv run unrot topics

# View your stats
uv run unrot stats
```

## Commands

| Command | Description |
|---|---|
| `unrot start` | Launch the interactive TUI quiz app |
| `unrot topics` | List all topics and subtopics |
| `unrot stats` | Show performance statistics (non-TUI) |
| `unrot config` | Show current configuration |
| `unrot generate-questions` | Print a prompt for the opencode agent to generate questions |

## Question Generation

Questions are generated by the `dbt-quiz-master` opencode agent (`.opencode/agent/dbt-quiz-master.md`), which searches dbt docs and stores questions in DuckDB with full provenance.

```bash
# Generate questions (prints a prompt for the opencode agent)
uv run unrot generate-questions --topic dbt --difficulty intermediate --count 10
```

No default model is set — the agent inherits your global opencode model configuration.

## Architecture

- **TUI:** Textual (screens: welcome → quiz → summary → stats)
- **CLI:** Typer (non-interactive commands)
- **Database:** DuckDB at `~/.unrot/unrot.duckdb`
- **Models:** Pydantic v2
- **Topics:** `data/topics.yaml`
